# Vibe Web Screensaver

**Your vibe. Your weather.**

Vibe Web Screensaver is a collection of single-page web experiences designed to work as interactive screensavers.

Each page is an artistic interpretation of weather, atmosphere, and mood. Rather than simply displaying weather information, these experiences turn it into a visual environment through motion, light, and ambient effects.

## Experiences

### STRIKE

A cinematic thunderstorm with animated rain, procedural lightning, and live local weather.

### DRIFT

An independent atmospheric experience with its own visual identity.

## Philosophy

Weather is more than numbers, icons, and forecasts. It can be a mood, a feeling, or an entire atmosphere.

Vibe Web Screensaver explores this idea through minimal, immersive web experiences that bring the environment to life on your screen.

## Quick Start

1. Choose an experience: `strike` or `drift`.
2. Copy the selected page's files to the root directory of your web server.
3. Configure your web server or reverse proxy to serve the page.
4. Open the page in your browser.

The experiences are built as static web pages and require no application backend or build process.

## Project Status

This is an ongoing personal project. New experiences and visual interpretations may be added over time.
